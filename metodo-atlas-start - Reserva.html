Dúvidas

Perguntas frequentes sobre o Start

O Atlas Start é acompanhamento contínuo?

Não. O Start é um direcionamento inicial, pontual, para você começar com mais clareza. O acompanhamento contínuo é feito pelo Método Atlas.

O que acontece depois que eu respondo a avaliação?

Kevin analisa suas informações individualmente e monta o seu direcionamento inicial a partir do que você descreveu.

Como recebo meu direcionamento?

Você recebe diretamente do Kevin, com tudo organizado para você aplicar desde o primeiro dia.

O Start é indicado para qualquer objetivo?

O Start funciona bem como ponto de partida para diferentes objetivos. Se você já sabe que vai precisar de ajustes contínuos ao longo do tempo, o Método Atlas costuma ser mais indicado.
